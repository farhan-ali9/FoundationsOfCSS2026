# FCSS Python Basics Homework
**Purpose:** practise the same skills taught in the Programming with Python practical.


Attempt the tasks yourselves and bring:
- your `.ipynb` file,
- any errors you could not solve,
- questions for the next tutorial.

## Task 1: Variables and output
Create these variables:

```python
name = "your name"
study_hours = 3
```

Print:

`<name> studied Python for 3 hours.`

Use an f-string.

## Task 2: Numbers
A student receives these quiz scores:

```python
score1 = 62
score2 = 75
score3 = 83
```

Calculate and print the average.

## Task 3: Lists
Create:

```python
scores = [62, 75, 83, 49]
```

1. Print the first score.
2. Print the last score.
3. Add `91`.
4. Print the number of scores.
5. Print the average.

## Task 4: Dictionaries
Create a dictionary representing one social-media post with:
- `id`
- `text`
- `likes`

Then:
1. print the text,
2. change the number of likes,
3. add a key called `platform`,
4. print the dictionary.

## Task 5: Comparisons
Using:

```python
likes = 12
```

Write expressions that check:
1. whether likes are at least 10,
2. whether likes equal exactly 12,
3. whether likes are below 5.

Before running them, write down what you expect each expression to return.

## Task 6: Conditions
Write an `if` / `else` statement:

- if a score is at least 50, print `Pass`
- otherwise print `Not yet passed`

Test with:
- 49
- 50
- 80

## Task 7: Combined task
Use:

```python
student = {
    "name": "Alex",
    "scores": [55, 70, 40]
}
```

1. calculate the average,
2. print the name and average,
3. print `Pass` if the average is at least 50, otherwise `Not yet passed`.
